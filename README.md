# Calcite UI Icons

This branch contains the [Calcite UI Icons](https://developers.arcgis.com/calcite-design-system/icons/) used in the course.

The icons can be found in the [`calcite-icons/`](calcite-icons/) folder:

| Icon            | File              |
| --------------- | ----------------- |
| Download        | `download-32.svg` |
| GPS Off         | `gps-off-32.svg`  |
| GPS On          | `gps-on-32.svg`   |
| GPS On (Filled) | `gps-on-32-f.svg` |
| Offline         | `offline-32.svg`  |
| Online          | `online-32.svg`   |
